# 🎵 SQL Music Store Analysis

## 📌 About the Project

This project analyzes a **Music Store database using SQL** to answer real-world business questions related to customers, sales, artists, genres, and invoices.

The project covers **Easy, Moderate, and Advanced SQL queries** to demonstrate practical data analysis skills.

## 🛠️ SQL Skills Used

* SELECT, WHERE, ORDER BY
* GROUP BY & Aggregate Functions
* JOINs
* Subqueries
* CTEs
* Recursive CTEs
* Window Functions
* ROW_NUMBER()
* PARTITION BY

## 📊 Key Analysis

* 👤 Identified the senior-most employee
* 🌍 Analyzed invoice distribution by country
* 💰 Found the highest-revenue city
* 🏆 Identified the best customer
* 🎸 Analyzed Rock music listeners and artists
* 🎵 Found the most popular genre by country
* 💳 Identified the highest-spending customer in each country
* 📈 Analyzed spending by customers and artists
